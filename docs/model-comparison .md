# LLM 모델 비교와 선정 보고서


## 1. 비교 과업

- **과업:** 거래처(갑)에 대금 지급 일정을 묻는 문의 메일 작성. 정확한 날짜가 어렵다면 대략적인 일정이라도 받아야 함
- **타겟 사용자:** 거래처(갑)에게 대금 일정을 확인하는 것이 힘든 실무자
- **입력:** 붙여넣은 텍스트 전문
- **출력:** 정해진 양식이 있는 정중한 문의 메일

## 2. 비교 대상 모델

| 서비스 | 표시 이름(화면 원문) | 요금제 | 실행 시점 |
|---|---|---|---|
| Claude | sonnet 5.5 | 무료 | 2026-11-24 |
| ChatGPT | gpt-6 | 무료 | 2026-11-24 |
| Gemini | auto | 무료 | 2026-11-24 |

- **무료 요금제 모델:** 세 모델 모두 무료 요금제로 실행했습니다. (조건 충족: 무료 요금제 모델 1개 이상)
- **실행 조건:** 세 서비스 모두 새 대화창에서 시스템 프롬프트 없이 같은 과업 프롬프트를 입력하고, 첫 응답을 기준으로 삼았습니다.

## 3. 실행에 사용한 입력

**입력 (세 모델 동일)**

```
거래처(갑)의 담당자에게 보낼 대금 지급 일정 문의 메일을 작성해 줘.
- 우리 회사: 한빛디자인 / 담당자: 실무 담당자 (이름 미정)
- 거래처: 가온전자 재무팀
- 거래 내용: 신제품 패키지 디자인 용역
- 청구서 번호: INV-2026-0412 / 청구일: 2026-10-15 / 청구 금액: 3,300,000원
- 약정 지급일: 청구일로부터 30일 이내 (현재 미입금 상태)
- 요청: 정확한 지급일이 어렵다면 대략적인 지급 예정 시기라도 알려 달라고 정중히 요청
- 출력: 제목, 인사, 청구 내역 확인, 일정 문의, 대안 요청, 마무리 순서의 메일
```

## 4. 비교 기준

점수는 1에서 5이며 클수록 좋습니다.

| 번호 | 기준 | 보는 것 |
|---|---|---|
| 1 | 형식 준수 | 제목, 인사, 청구 내역, 일정 문의, 대안 요청, 마무리 여섯 요소와 순서 |
| 2 | 정중함과 어조 | 갑에게 쓰는 비즈니스 톤, 재촉하는 느낌 여부 |
| 3 | 사실 오류 | 입력에 없는 정보 추가, 날짜 계산, 숫자 정확성 |
| 4 | 일정 확보 유도 | 정확한 날짜가 어려울 때 대략 시기를 요청하는 정도 |

## 5. 모델별 점수와 근거

| 비교 기준 | Claude | ChatGPT | Gemini | 근거 |
|---|---|---|---|---|
| 1. 형식 준수 | 5 | 5 | 5 | 세 모델 모두 프롬프트에서 요구한 요소를 갖추고 있음 |
| 2. 정중함과 어조 | 3 | 4 | 3 | Claude: 중복표현이 다수. 메일이 정신없어 보이는 경향이 있음<br>ChatGPT: 비슷한 내용이 다수 나옴. 담백한 비지니스 표현이 괜찮은듯<br>Gemini: 기한 경과를 꼬집으며 언제 지급예정인지 물어봐서 재촉의 느낌이 강함 |
| 3. 사실 오류 | 5 | 5 | 5 | 세 모델 모두 입력된 정보만을 사용함. |
| 4. 일정 확보 유도 | 5 | 5 | 5 | 세 모델 모두 이 부분은 딱히 발견되지 않음 |
| 합계 (20점 만점) | 18 | 19 | 18 | |

## 6. 최종 선정 결론

- **선정 모델:** ChatGPT (gpt-6)
- **선정 근거:** 셋 다 문장 구성이나 내용은 비슷하나 그 중에서 gpt-6가 가장 담백한 표현을 사용하고 있었음.
  일부 표현이 중복되는 점이 아쉽기는 하나 수정할 부분이 많지 않을 것 같아 선정함.

안녕하세요, 가온전자 재무팀 담당자님.

바쁘신 가운데 번거롭게 해 드려 죄송하며, 확인해 주시면 감사하겠습니다.
회신 기다리겠습니다.
감사합니다.
한빛디자인
[담당자 이름] 드림
연락처: [전화번호] / [이메일 주소]

메일 초안을 위 카드에 정리했습니다. 요청하신 순서(제목, 인사, 청구 내역 확인, 일정 문의, 대안 요청, 마무리)로 구성했습니다.

### ChatGPT (gpt-6)

```
**제목: [한빛디자인] 신제품 패키지 디자인 용역 대금 지급 일정 문의**

안녕하세요. 가온전자 재무팀 담당자님.

한빛디자인 실무 담당자입니다.

당사에서 진행한 신제품 패키지 디자인 용역과 관련하여 청구드린 대금의 지급 일정을 문의드리고자 메일드립니다.

아래 청구 내역 확인 부탁드립니다.

- **거래 내용:** 신제품 패키지 디자인 용역
- **청구서 번호:** INV-2026-0412
- **청구일:** 2026년 10월 15일
- **청구 금액:** 3,300,000원
- **약정 지급 기한:** 청구일로부터 30일 이내 (2026년 11월 14일까지)

현재까지 해당 대금의 입금이 확인되지 않아 지급 진행 상황을 확인하고자 합니다.

번거로우시겠지만 해당 청구 건의 정확한 지급 예정일을 확인하여 회신해 주시면 감사하겠습니다.

만약 현재 정확한 지급일 안내가 어려우시다면, 대략적인 지급 예정 시기나 예상 일자라도 알려주시면 당사 내부 자금 일정 관리에 큰 도움이 될 것 같습니다.

바쁘시겠지만 확인 후 회신 부탁드립니다.

감사합니다.

**한빛디자인 드림**

작성 포인트
- 미입금 사실을 감정적인 표현 없이 객관적으로 전달했습니다.
- 약정 지급 기한이 지났다는 점을 명확히 표시했습니다.
- 정확한 날짜가 어렵더라도 예상 시기를 회신해 달라는 대안을 제시했습니다.
- 거래처와의 관계를 고려해 정중하지만 지급 일정 확인의 필요성이 드러나도록 작성했습니다.
```
